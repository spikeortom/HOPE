# HOPE（原名 H.O.P.E.）(Haphazard Overview of Partner Enterprises)

> **HOPE** = Haphazard Overview of Partner Enterprises(合作企业随意汇总)

> 🤖 **本项目使用 AI 生成制作**，资料与数据均来源于互联网公开资料（公司公告、年报、官方网站与权威媒体报道），条目中尽量附上来源链接。内容仅供参考，如有出入，请以官方公开信息为准。

> 🇬🇧 **English**: [README_EN.md](README_EN.md) (full README) · [Going Global](Going-Global.md) (guide) — an open dataset documenting how companies go global.

## 📌 项目简介

HOPE 是一份**企业海外扩张与跨境合作关系**开放数据集，记录企业走向全球的过程：谁在向全球供货、谁在海外建厂并购。收录企业既有《财富》世界500强的大型集团，也有各行业优秀企业；对求职者来说，也是一份了解企业实力的参考。包括：

1. **海外客户关系**：企业向海外客户供货
2. **合资企业**：与海外企业成立合资公司
3. **海外并购**：收购海外企业或业务
4. **技术授权**：向海外企业授权技术/产品
5. **供应商关系**：从海外企业采购关键零部件

## 🤝 合作关系类型

- **供应-客户**：宁德时代→特斯拉、星宇→宝马

## ⚖️ 法规与合规

海外建厂、并购、合资与供应活动涉及东道国外资审查、出口管制、供应链尽职调查等多领域监管，背景说明见 **[docs/REGULATORY.md](docs/REGULATORY.md)**；`data/labor-rights.json` 收录主要经济体的劳动法规与供应链合规参考。本数据集仅为公开信息汇总，不构成法律或投资建议。

## 📊 数据结构

### companies.json
企业条目为主体，包含：
- 企业基本信息（中英文名、股票代码、行业、总部）
- 海外合作伙伴列表
- 产品和业务信息

### collaborations.json
海外合作关系明细，每条包含：
- 合作类型（供应客户 / 海外建厂 / 海外办事处 / 合资企业 / 海外并购 / 技术授权 / 外包代工）
- 企业（`domestic.id` 对应 companies.json）与海外对象
- 涉及产品、开始年份、海外地点、产能、状态等

### labor-rights.json
各国劳动法规与供应链合规参考：
- 主要经济体的劳动/尽职调查法规框架
- 合规信息查询渠道
- 合规评级参考标准（档位定义）

字段说明详见 [docs/data-viz.md](docs/data-viz.md)。

> 💡 修改 `data/` 下的数据后，运行 `npm run docs` 可自动更新[《企业合作关系一览》](docs/企业合作关系一览.md)。
